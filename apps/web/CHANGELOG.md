# Changelog

All notable changes to `@gamingalo/web` are recorded here. This project follows [Semantic Versioning](https://semver.org/).

## [0.3.0] - 2026-11-11

### Added

* The home page lists live games.
* Game player: plays a game from its own origin in a sandboxed frame, and gives it a play token when it asks.
* Creator page: API tokens, shown once and revocable, and games with their versions, preview links and a way to make a version live.

## [0.2.0] - 2026-11-11

### Added

* Sign-in page: play as a guest after an age question, or sign in with a passkey.
* Account page: display name, passkeys, analytics consent, data download, sign out and account deletion.
* The header shows who is signed in.

## [0.1.0] - 2026-11-01

### Added

* Application shell with navigation and a skip link, using Vertical Slice Architecture.
* Home page, and a service status panel connected to the web services.
