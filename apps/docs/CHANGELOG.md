# Changelog

All notable changes to `@gamingalo/docs` are recorded here. This project follows [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-11

### Added

* Documentation site built with Fumadocs, as a static export for GitHub Pages, with search in the browser.
* Lit Grid, a small design system: color, type and shape tokens, and `Badge`, `Kbd`, `Tile`, `Swatch` and `TileLogo`.
* Pages for the SDK, plugins, CLI, publishing, versioning, AI agents and the design system, and every module's changelog.
