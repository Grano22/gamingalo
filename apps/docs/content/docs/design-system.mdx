Lit Grid has one idea: a 3 by 3 board where **one square is lit**, as in the game skeleton. Lit means active or important. Everything else stays quiet, so the lit thing is always easy to find.

<TileLogo size={64} title="The Gamingalo mark" />

## Color

Signal marks what's lit. Pulse marks links and focus. Each has a deep shade, so text keeps WCAG AA contrast on light backgrounds.

## Type

* **Space Grotesk** for headings.
* **IBM Plex Sans** for text.
* **JetBrains Mono** for code and keys.

## Shape

Tiles have a 6 px radius. A lit tile has its top-left corner cut, like the notch on a key, and a signal-colored top edge.

## Components

| Component | Use |
|---|---|
| `<Badge tone="stable" />` | <Badge tone="stable" /> <Badge tone="beta" /> <Badge tone="planned" /> <Badge tone="breaking" /> Status. Always shows a label, so color is never the only signal. |
| `<Kbd>` | Keys, such as <Kbd>Space</Kbd> or <Kbd>1</Kbd> to <Kbd>9</Kbd> |
| `<Tile>`, `<TileGrid>` | Cards, with `lit` for one of them |
| `<Swatch>` | A token's color, name and value |
| `<TileLogo>` | The mark. Its lit square moves only when the reader allows motion. |

## Rules

* At most one lit thing per view.
* Never use color alone to carry meaning.
* Motion is decoration only, and stops under `prefers-reduced-motion`.
