# Server SDK requirements

For anyone who wants to host their own game servers. Custom servers must work before the Server SDK exists, so the protocol comes first.

| ID | Requirement | Origin | Phase |
|---|---|---|---|
| SRV-001 | Documented custom server protocol: registration, player authentication, game modes and matchmaking, which any server can implement | Proposed | P3 |
| SRV-002 | Server SDK for hosting game servers, implementing that protocol | Original | P5 |
| SRV-003 | Certification tools for Gamingalo official certified servers | Proposed | P5 |
