# Game Wrapper requirements

Core SDK plus adapters that mount it on a game.

| ID | Requirement | Origin | Phase |
|---|---|---|---|
| WRAP-001 | Mount on a canvas in plain JavaScript and inject SDK features | Original | P1 |
| WRAP-002 | Three.js adapter | Proposed | P1 |
| WRAP-003 | WASM bridge and Godot adapter | Proposed | P1 |
| WRAP-004 | Angular, React and Vue mounts | Original | P2 |
| WRAP-005 | Game stats: unique players, online and played counts, visits, browser and PWA, country. Uses a first-party ID, see D-18 | Changed | P2 |
| WRAP-006 | Quick Resume with local storage (free), using a save and restore contract implemented by the game | Changed | P2 |
| WRAP-007 | Quick Resume with cloud storage across devices (paid plan) | Original | P3 |
| WRAP-008 | Further adapters, in order of demand: Babylon.js, PlayCanvas, Phaser, Unity | Proposed | P3 |
